## 1. 구현과 시뮬레이션

**구현**은 문제에 적힌 규칙을 그대로 코드로 옮기는 문제다. **시뮬레이션**은 그중에서 시간이 흐르며 상태가 바뀌는 과정(로봇이 움직이고, 손가락이 이동하는 것)을 한 단계씩 직접 돌려 보는 문제다. 알고리즘 아이디어는 어렵지 않고, 규칙을 빠뜨리거나 인덱스를 틀리는 실수가 점수를 가른다.

### 먼저 제한사항을 본다

구현 문제는 N이 작은 경우가 많다. 1주차에서 배운 대로 제한사항의 최댓값으로 연산 횟수를 먼저 어림해 본다. 공원 산책은 `park` 가 최대 50 × 50, 명령은 최대 50개, 한 명령은 최대 9칸이다. 최대 50 × 9 = 450번만 움직이면 되므로 **문제에 적힌 대로 한 칸씩 전부 돌려도 충분하다.** 빠르게 푸는 방법을 찾을 필요가 없다.

### 구현 문제 푸는 순서

1. **규칙을 한 줄씩 끊어 적는다.** 예: "한 칸씩 이동", "공원 밖이면 무시", "장애물이면 무시", "무시하면 원래 자리로".
2. **입력을 다루기 좋은 모양으로 바꾼다.** 예: 공원 산책은 `park` 를 훑어서 `S` 의 좌표 `(r, c)` 를 먼저 찾는다.
3. **규칙을 적은 순서 그대로 코드로 쓴다.** 최적화하지 않는다.
4. **예제 하나를 손으로 따라가며 중간 값을 출력해 본다.** 마지막 결과만 맞추지 말고 `(r, c)` 가 매 단계 어디에 있는지 확인한다.

## 2. 2차원 배열과 방향 벡터

### 행과 열

2차원 배열은 `board[r][c]` 로 읽는다. `r` 은 위에서부터 몇 번째 줄(행), `c` 는 왼쪽부터 몇 번째 칸(열)이다. 둘 다 0부터 시작한다.

```java
String[] board = {
    "abc",
    "def",
    "ghi"
};

// 행 개수 = 3, 한 행의 길이 = 3
int n = board.length;
int m = board[0].length();

// 1행 2열 → 'f'
char ch = board[1].charAt(2);
```

### 방향 벡터

현재 칸 `(r, c)` 에서 한 칸 움직일 때 `r` 과 `c` 가 얼마나 바뀌는지를 배열로 만들어 둔 것이다. 방향마다 `if` 를 4개 쓰는 대신 **반복문 하나**로 처리한다.

| 방향 | 인덱스 | `dr` | `dc` |
| --- | --- | --- | --- |
| 위 | 0 | -1 | 0 |
| 아래 | 1 | +1 | 0 |
| 왼쪽 | 2 | 0 | -1 |
| 오른쪽 | 3 | 0 | +1 |

위로 가면 행 번호가 **줄어든다**는 점이 수학 좌표계와 반대라 가장 헷갈린다.

```java
int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};

int r = 1;
int c = 1;

for (int i = 0; i < 4; i++) {
    int nr = r + dr[i];
    int nc = c + dc[i];

    // 범위를 먼저 확인하고, 그다음에 board[nr][nc] 를 읽는다
    if (nr < 0 || nr >= n || nc < 0 || nc >= m) {
        continue;
    }

    System.out.println(board[nr].charAt(nc));
}
```

위 보드에서 `(r, c) = (1, 1)`, 즉 `'e'` 에서 돌리면 이렇게 된다.

| i | `(nr, nc)` | 읽는 값 |
| --- | --- | --- |
| 0 (위) | (0, 1) | `'b'` |
| 1 (아래) | (2, 1) | `'h'` |
| 2 (왼쪽) | (1, 0) | `'d'` |
| 3 (오른쪽) | (1, 2) | `'f'` |

모서리 `(0, 0)` 에서 돌리면 `i = 0` 은 `(-1, 0)`, `i = 2` 는 `(0, -1)` 이 되어 범위 검사에서 걸러지고, 아래와 오른쪽 두 칸만 남는다.

### 문자로 방향이 주어질 때

공원 산책처럼 `N`, `S`, `W`, `E` 가 주어지면 문자열에서 위치를 찾아 그 인덱스로 방향 벡터를 고른다.

```java
String dirs = "NSWE";
int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};

// 'E' → 3 → dr[3] = 0, dc[3] = +1
int k = dirs.indexOf('E');
```

### 좌표로 바꿔서 거리 구하기

키패드 누르기처럼 번호가 붙은 칸은 번호를 `(행, 열)` 로 바꾸면 거리를 계산할 수 있다. 상하좌우로만 움직일 때 두 칸 사이의 최소 이동 횟수는 **맨해튼 거리**다.

```java
// 키패드 1~9 는 3열 배열이라 번호에서 바로 좌표가 나온다
// 5 → (5 - 1) / 3 = 1행, (5 - 1) % 3 = 1열
int num = 5;
int row = (num - 1) / 3;
int col = (num - 1) % 3;

// (r1, c1) 에서 (r2, c2) 까지 거리
int dist = Math.abs(r1 - r2) + Math.abs(c1 - c2);
```

`0`, `*`, `#` 은 이 식에 들어맞지 않으니 따로 좌표를 정해 준다.

## 3. 자주 쓰는 Java 문법

1주차와 같이 `solution` 메서드의 매개변수로 입력이 들어오고 `return` 으로 답을 낸다. 이번 주 문제는 입력이 대부분 `String[]` 이다.

| 하고 싶은 것 | 코드 |
| --- | --- |
| 배열 길이 | `String[] park` 의 개수는 `park.length`, 그 안 문자열의 길이는 `park[i].length()` |
| 문자열의 i번째 글자 | `park[r].charAt(c)` |
| 글자 비교 | `park[r].charAt(c) == 'X'` (작은따옴표, `char` 끼리 `==`) |
| 문자열 → 글자 배열 | `char[] cs = s.toCharArray();` |
| 글자 → 숫자 | `int d = ch - '0';` (`'7' - '0' == 7`) |
| 숫자 문자열 → 숫자 | `Integer.parseInt("12")` |
| 공백으로 쪼개기 | `String[] t = "E 2".split(" ");` → `t[0]` 은 `"E"`, `t[1]` 은 `"2"` |
| 문자열에서 위치 찾기 | `"NSWE".indexOf('E')` → `3` (없으면 `-1`) |
| 절댓값 | `Math.abs(x)` |
| 2차원 배열 만들기 | `int[][] g = new int[n][m];` (전부 0으로 시작) |
| 배열로 답 반환 | `return new int[]{r, c};` |
| 글자를 이어 붙이기 | `StringBuilder sb = new StringBuilder();` → `sb.append('L');` → `sb.toString()` |
| 문자열 같은지 비교 | `hand.equals("left")` |

### Java에서 자주 틀리는 것

- **행·열을 `x`, `y` 로 뒤집기**: `board[r][c]` 는 `r` 이 세로(행)다. 수학 좌표 `(x, y)` 의 `x` 가 가로라서 `board[x][y]` 로 쓰면 가로 세로가 바뀐다. 바탕화면 정리의 `lux`, `rdx` 처럼 `x` 라는 이름이 붙어 있어도 행(세로) 값인 경우가 있으니 **문제의 설명을 먼저 확인**한다.
- **범위 검사 전에 배열을 읽기**: `board[nr][nc]` 를 먼저 읽으면 `nr` 이 -1일 때 `ArrayIndexOutOfBoundsException` 이 난다. 항상 범위 조건을 앞에 두고 `&&` 로 이어서 쓴다. `if (nr >= 0 && nr < n && board[nr][nc] == 'X')` 는 `nr` 이 범위 밖이면 뒤를 읽지 않아 안전하다.
- **`length` 와 `length()` 혼동**: 배열(`String[]`, `int[]`)은 `.length`, 문자열(`String`)은 `.length()` 다. `park[0].length` 라고 쓰면 컴파일 오류가 난다.
- **문자열을 `==` 로 비교**: `String` 의 `==` 는 내용이 아니라 같은 객체인지를 비교한다. `split` 으로 나온 문자열이나 입력으로 받은 문자열은 `"left"` 와 내용이 같아도 `false` 가 될 수 있다. 문자열은 `.equals()` 를 쓴다. 한 글자(`char`)는 `==` 로 비교해도 된다.
- **여러 칸을 한 번에 이동하고 도착 칸만 검사하기**: 한 번에 `n` 칸 가는 규칙이라도 코드는 한 칸씩 `n` 번 움직이며 **매번** 검사한다. 도착 칸만 보면 중간에 막힌 칸을 지나가 버린다. 이동이 취소될 수 있다면 `r`, `c` 는 건드리지 말고 `nr`, `nc` 에 임시로 움직여 보다가, 끝까지 통과했을 때만 `r = nr; c = nc;` 로 반영한다.
