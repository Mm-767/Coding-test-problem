8주차 커리큘럼 설계안
1주차: 코딩 테스트 입문 & 그리디(Greedy)
학습 내용: 시간 복잡도의 개념 이해 및 매 순간 가장 좋아 보이는 선택을 하는 그리디 알고리즘 기초 학습.

2주차: 구현(Implementation) & 시뮬레이션
학습 내용: 머릿속 아이디어를 실수 없이 코드로 구현하는 훈련, 2차원 공간 상의 방향 벡터 활용법 학습.

3주차: 자료구조 기초 & DFS/BFS
학습 내용: 스택과 큐 자료구조의 원리, 재귀 함수의 동작 및 대표적인 그래프 탐색 알고리즘 기초.

4주차: 정렬(Sorting) & 이진 탐색(Binary Search)
학습 내용: 선택/삽입 정렬의 원리 및 탐색 범위를 절반씩 좁혀나가는 이진 탐색(바이너리 서치) 학습.

5주차: 다이나믹 프로그래밍(DP)
학습 내용: 이미 계산된 결과를 메모리에 저장하여 효율성을 극대화하는 보텀업/탑다운 설계법 맛보기.

6주차: 최단 경로 알고리즘 기초
학습 내용: 그래프 상에서 지점 간 가장 짧은 경로를 찾는 다익스트라(Dijkstra) 알고리즘 기본 원리 및 우선순위 큐 활용법 학습.

7주차: 백엔드 특화 '개발형 코딩 테스트' 개념
학습 내용: 카카오 등 실제 기업에서 출제되는 REST API 호출 및 JSON 데이터 파싱 실습.

8주차: 수학 및 필수 탐색 알고리즘 & 종합 복습
학습 내용: 코딩 테스트 단골 유형인 소수 판별, 투 포인터, 구간 합 빠르게 계산하기 학습.
